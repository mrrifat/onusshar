## ⌨️ How to Type

```
ami          → আমি
tumi         → তুমি
bangla       → বাংলা
bhalobashi   → ভালোবাসি
```

**Vowels:** a, i, u, e, o, ii, uu, oi, ou
**Consonants:** k, kh, g, ch, j, t, th, d, n, p, b, bh, m, r, l, sh, s, h
**Retroflexes (capitals):** T→ট, D→ড, R→ড়, N→ণ
**Special:** ~ Ng H ^ ..

Full guide: Check the web version for interactive examples.
