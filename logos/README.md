# Onusshar Logos

Brand assets for the Onusshar Bengali Phonetic Keyboard.

## Logo Files

- **onusshar-icon-256.svg** - 256×256px square icon (primary)
- **onusshar-icon-200.svg** - 200×200px square icon

## Design

The Onusshar logo features the Bengali script "অনুস্বর" (Onusshar) in white text on a blue background (#2563eb). The design emphasizes Bengali typography and modern, clean aesthetics.

## Usage Guidelines

- Use the logo on blue, white, or neutral backgrounds
- Maintain minimum padding around the logo (at least 10% of logo dimensions)
- Do not distort, rotate, or modify the logo colors
- For print materials, ensure Bengali font rendering is supported

## Color Palette

- **Primary Blue**: #2563eb (RGB: 37, 99, 235)
- **Text White**: #ffffff (RGB: 255, 255, 255)

## Font

The logo uses Bengali fonts in this priority order:
1. Noto Sans Bengali
2. Kalpurush
3. SolaimanLipi
4. System Bengali sans-serif fallback
