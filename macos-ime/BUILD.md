# Building Onusshar macOS Installer

This guide explains how to build the Onusshar macOS installer from source.

## Prerequisites

### Required Software

1. **Xcode 13 or later**
   - Install from Mac App Store
   - Or download from: https://developer.apple.com/xcode/

2. **Xcode Command Line Tools**
   ```bash
   xcode-select --install
   ```

3. **Node.js 18 or later** (for dictionary dependency)
   - Download: https://nodejs.org/
   - Or install with Homebrew:
     ```bash
     brew install node
     ```

### System Requirements

- macOS Monterey (12.0) or later
- Intel or Apple Silicon Mac
- 4 GB RAM minimum
- 2 GB free disk space for build

## Build Steps

### Option 1: Automated Build (Recommended)

Run the automated build script:

```bash
cd macos-ime
chmod +x build-installer.sh
./build-installer.sh
```

This will:
1. Build the Xcode project (OnussharInputMethod.app)
2. Create a .pkg installer with postinstall scripts
3. Package resources (Welcome.html, ReadMe.html)
4. Create a .dmg disk image
5. Output: `dist/Onusshar-0.3.1.dmg`

### Option 2: Manual Build

#### Step 1: Install Dependencies

```bash
cd ..
npm install
cd macos-ime
```

#### Step 2: Build Xcode Project

```bash
xcodebuild -project OnussharInputMethod.xcodeproj \
           -scheme OnussharInputMethod \
           -configuration Release \
           -derivedDataPath build/DerivedData \
           build
```

Output: `build/DerivedData/.../Onusshar.app`

#### Step 3: Create Package Root

```bash
mkdir -p build/pkgroot/Applications
cp -R build/DerivedData/.../Onusshar.app build/pkgroot/Applications/
```

#### Step 4: Build .pkg

```bash
pkgbuild --root build/pkgroot \
         --identifier com.onusshar.inputmethod \
         --version 0.3.1 \
         --scripts scripts \
         --install-location / \
         build/Onusshar-0.3.1.pkg
```

#### Step 5: Create Product Package (with installer UI)

```bash
mkdir -p build/Resources
# Create Welcome.html and ReadMe.html (see build-installer.sh)

productbuild --package build/Onusshar-0.3.1.pkg \
             --resources build/Resources \
             build/OnussharInstaller-0.3.1.pkg
```

#### Step 6: Create DMG

```bash
mkdir -p build/dmg dist
cp build/OnussharInstaller-0.3.1.pkg build/dmg/OnussharInstaller.pkg
# Add ReadMe.txt

hdiutil create -volname "Onusshar Bengali Keyboard" \
               -srcfolder build/dmg \
               -ov -format UDZO \
               dist/Onusshar-0.3.1.dmg
```

## Installer Components

### 1. Postinstall Script

Location: `scripts/postinstall`

This script runs after installation and:
- Copies `Onusshar.app` to `/Library/Input Methods/`
- Sets proper permissions (`chmod 755`, `chown root:wheel`)
- Restarts Input Method server (`killall IMKServer`)
- Displays activation instructions

### 2. Welcome Screen

Location: `build/Resources/Welcome.html` (generated by build script)

Shows:
- Product name and version
- Feature highlights
- Example typing demonstration
- Installation instructions

### 3. ReadMe

Location: `build/Resources/ReadMe.html` (generated by build script)

Contains:
- System requirements
- Quick start guide
- Phonetic typing examples
- Support information
- Uninstallation instructions

### 4. DMG Contents

The final `.dmg` contains:
- `OnussharInstaller.pkg` - The installer package
- `ReadMe.txt` - Plain text instructions

## Testing the Installer

### 1. Mount the DMG

```bash
open dist/Onusshar-0.3.1.dmg
```

Or double-click in Finder.

### 2. Run the Installer

1. Double-click `OnussharInstaller.pkg`
2. Click "Continue" through the wizard
3. Agree to license terms
4. Select installation location (default: Macintosh HD)
5. Click "Install"
6. Enter administrator password
7. Installation completes

### 3. Verify Installation

Check if app was installed:
```bash
ls -la "/Library/Input Methods/Onusshar.app"
```

Check permissions:
```bash
ls -la "/Library/Input Methods/" | grep Onusshar
# Should show: drwxr-xr-x ... root wheel ... Onusshar.app
```

### 4. Activate Input Method

1. Open **System Settings** (or System Preferences on older macOS)
2. Go to **Keyboard** → **Input Sources**
3. Click the **+** button
4. Scroll to **Bengali**
5. Select **Onusshar**
6. Click **Add**

### 5. Test Typing

1. Open TextEdit or any app
2. Press **Control+Space** to switch to Onusshar
3. Type "ami bangla likchi"
4. Should see: "আমি বাঙলা লিকছি"

## Troubleshooting

### Xcode Build Failed

**Problem:** `xcodebuild: error: Could not resolve package dependencies`

**Solution:**
```bash
rm -rf ~/Library/Developer/Xcode/DerivedData
xcodebuild -resolvePackageDependencies
```

### App Not Appearing in Input Sources

**Problem:** Onusshar doesn't show in Input Sources list

**Solution:**
1. Verify installation:
   ```bash
   ls -la "/Library/Input Methods/Onusshar.app"
   ```

2. Check Info.plist:
   ```bash
   plutil -p "/Library/Input Methods/Onusshar.app/Contents/Info.plist" | grep InputMethodConnectionName
   ```

3. Restart Input Method server:
   ```bash
   killall IMKServer
   ```

4. Logout and login again (or restart Mac)

### Permission Denied During Installation

**Problem:** Installer fails with permission error

**Solution:**
1. Run installer with administrator password
2. Check target directory exists:
   ```bash
   ls -la /Library/Input\ Methods/
   ```

3. If directory doesn't exist:
   ```bash
   sudo mkdir -p "/Library/Input Methods"
   sudo chown root:wheel "/Library/Input Methods"
   ```

### IMKServer Crash

**Problem:** Input method crashes when switching

**Solution:**
1. Check Console.app for crash logs
2. Look for errors in `/Library/Logs/`
3. Verify app is properly signed:
   ```bash
   codesign -vv "/Library/Input Methods/Onusshar.app"
   ```

4. Rebuild with debug symbols:
   ```bash
   xcodebuild -configuration Debug
   ```

### DMG Creation Failed

**Problem:** `hdiutil: create failed - Resource busy`

**Solution:**
1. Unmount existing DMG:
   ```bash
   hdiutil detach "/Volumes/Onusshar Bengali Keyboard"
   ```

2. Clear temporary files:
   ```bash
   rm -rf build/dmg/*
   ```

3. Retry creation

## Code Signing

### For Development (Ad-hoc Signing)

Xcode automatically signs with ad-hoc certificate during development:
```bash
codesign -s - "/Library/Input Methods/Onusshar.app"
```

### For Distribution (Developer ID)

1. **Obtain Developer ID Certificate:**
   - Join Apple Developer Program ($99/year)
   - Download "Developer ID Application" certificate from Apple

2. **Sign the App:**
   ```bash
   codesign --deep --force --verify --verbose \
            --sign "Developer ID Application: Your Name (TEAMID)" \
            --options runtime \
            --timestamp \
            "/Library/Input Methods/Onusshar.app"
   ```

3. **Sign the Package:**
   ```bash
   productsign --sign "Developer ID Installer: Your Name (TEAMID)" \
                build/OnussharInstaller-0.3.1.pkg \
                build/OnussharInstaller-0.3.1-signed.pkg
   ```

4. **Notarize (Required for macOS 10.15+):**
   ```bash
   xcrun notarytool submit dist/Onusshar-0.3.1.dmg \
                          --apple-id your@email.com \
                          --team-id TEAMID \
                          --password app-specific-password \
                          --wait
   ```

5. **Staple Notarization:**
   ```bash
   xcrun stapler staple dist/Onusshar-0.3.1.dmg
   ```

### Verify Signing

```bash
# Check app signature
codesign -dvvv "/Library/Input Methods/Onusshar.app"

# Check package signature
pkgutil --check-signature build/OnussharInstaller-0.3.1.pkg

# Check notarization
spctl -a -vvv -t install dist/Onusshar-0.3.1.dmg
```

## Build Customization

### Change Version

Edit `build-installer.sh`:
```bash
VERSION="0.3.2"
```

Also update Xcode project version:
1. Open `OnussharInputMethod.xcodeproj`
2. Select project in navigator
3. Update version in "General" tab

Or via command line:
```bash
xcrun agvtool new-version -all 0.3.2
```

### Change Bundle Identifier

Edit `OnussharInputMethod/Info.plist`:
```xml
<key>CFBundleIdentifier</key>
<string>com.yourcompany.onusshar</string>
```

Also update in `build-installer.sh`:
```bash
BUNDLE_ID="com.yourcompany.onusshar"
```

### Customize Installer UI

Edit HTML templates in `build-installer.sh`:
- `Welcome.html` - Welcome screen content
- `ReadMe.html` - ReadMe content

### Add More Files to DMG

Edit `build-installer.sh`, add files to DMG directory:
```bash
cp "your-file.pdf" "$DMG_DIR/"
```

## Universal Binary (Intel + Apple Silicon)

The Xcode project should build Universal Binary by default.

Verify:
```bash
lipo -info "/Library/Input Methods/Onusshar.app/Contents/MacOS/Onusshar"
# Should show: Architectures in the fat file: x86_64 arm64
```

To explicitly set:
1. Open Xcode project
2. Build Settings → Architectures
3. Set to "Standard Architectures (Apple Silicon, Intel)"

Or via command line:
```bash
xcodebuild -project OnussharInputMethod.xcodeproj \
           -scheme OnussharInputMethod \
           -configuration Release \
           ARCHS="x86_64 arm64" \
           build
```
