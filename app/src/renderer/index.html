About Onusshar

Onusshar is a modern, fast, open-source Bengali phonetic keyboard for Windows & macOS.

Version: 0.1.0

Type Bengali using familiar Roman/Latin letters with smart phonetic conversion.

Features

  • Smart phonetic conversion
  • System tray integration
  • Global hotkey support
  • Customizable settings
  • Cross-platform (Windows, macOS)
